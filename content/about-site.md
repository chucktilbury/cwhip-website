# About this site

This page explains how the Cwhip website is organized and how to use it.

- The **Home** page gives a short introduction to the project.
- The **Documentation** section contains the ordered technical documents.
- Documentation is grouped into Getting Started, Language & Compiler, Editor, Debugger, and Contributor Workflow.
- Documents remain maintained in their component repositories; the website imports them when built.
- Returning visitors who already know the project can use the prominent action button on the home page to reach working areas (discussions, announcements, or other tasks) without re-reading the introduction.

More detail can be added here as the site’s conventions settle.
